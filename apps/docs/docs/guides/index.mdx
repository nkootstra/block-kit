The [quickstart](/quickstart) renders a message. These guides take it from there: each one covers
a single job a real app has to do, with a working preview and the code behind it.

## Interactivity

<CardGroup cols={2}>
  <Card title="Handling actions" href="/guides/interactivity" icon="mouse-pointer-click">
    Respond to clicks, selects and inputs with `onAction`, read `state.values`, and update or delete
    the message they came from.
  </Card>
  <Card title="Modals" href="/guides/modals" icon="app-window">
    Open, push and update modals from an action, validate and submit them, and react to
    `response_action`.
  </Card>
  <Card title="External data" href="/guides/external-data" icon="database">
    Fill an `external_select`'s options from your own data with `onOptions`.
  </Card>
  <Card title="Connecting your app" href="/guides/connecting-your-app" icon="plug">
    Send real, signed Slack interaction payloads from the browser to an existing Bolt app.
  </Card>
  <Card title="Validation" href="/guides/validation" icon="circle-check">
    The checks Slack runs on a modal before `view_submission`, and how to trigger or override them.
  </Card>
</CardGroup>
