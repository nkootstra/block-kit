A header displays a short, bold line of plain text. Use it to introduce a distinct section
of a message or app surface. Slack doesn't apply any markdown to it.

<Preview
  payload={{
    blocks: [
      {
        type: "header",
        text: {
          type: "plain_text",
          text: "This is a header block",
          emoji: true,
        },
      },
    ],
  }}
/>

## Fields

## Examples

### Basic header

<Preview
  payload={{
    blocks: [
      {
        type: "header",
        text: { type: "plain_text", text: "Weekly release notes", emoji: true },
      },
    ],
  }}
/>

### Header with a section and divider

Headers are typically followed by content: a section, a divider, or both.

<Preview
  payload={{
    blocks: [
      {
        type: "header",
        text: { type: "plain_text", text: "Budget Performance", emoji: true },
      },
      {
        type: "section",
        text: {
          type: "mrkdwn",
          text: "*Q3 spend* is tracking 8% under budget across all teams.",
        },
      },
      { type: "divider" },
      {
        type: "section",
        text: { type: "mrkdwn", text: "Full breakdown is attached below." },
      },
    ],
  }}
/>

:::note
This library also renders the Block Kit Builder's `level` field (1–4) on headers, which
scales the text size. It's not part of the Slack API; `level` defaults to 2, Slack's
standard header size, and only affects rendering here.
:::
