`data_table` renders a grid with a header row, per-column sorting, and pagination once a table has
more than a handful of rows. It isn't part of the public `@slack/types` package, so treat this page's
field list as the reference.

### Cell

Each cell is one of four shapes, picked by `type`:

<TypeTable
  type={{
    raw_text: {
      type: '{ type: "raw_text", text: string }',
      description: "Plain text, sorted alphabetically.",
    },
    raw_number: {
      type: '{ type: "raw_number", value: number, text: string }',
      description:
        "A number with its own display text. Sorts numerically by `value`, displays `text`.",
    },
    url: {
      type: '{ type: "url", url: string, text?: string }',
      description: "A link, opened in a new tab. `text` defaults to the raw URL.",
    },
    rich_text: {
      type: "RichTextBlock",
      description:
        "A Slack rich text node: bold, italic, and other inline styles, links, and user mentions (named by `resolvers.user`, else a loading pill, or the outline of a missing user when `resolvers.user` doesn't know them, with Slack's \"Private user info\" tooltip).",
    },
  }}
/>

:::note
Sorting isn't configured through the payload. Clicking a header cycles that column through
ascending, descending, and back to the original order. With keyboard focus, a header shows its sort
caret and Slack's button focus ring (`--sbk-focus-ring`). Pagination controls appear automatically
once a table has more than 5 data rows, five rows to a page. Slack's `page_size` field (1 to 100,
default 5) isn't read, so a table always pages by 5. See [Limits](/reference/limits) for the
row, column and character limits.
:::

The toolbar's **More actions** button opens Slack's menu with **Copy table**, which copies the
whole table as tab-separated text that pastes into a spreadsheet, and **Download table**, which
saves it as `table.csv`. Both take every row, header first, in the payload's order, whatever the
sort or page. In the CSV, a cell a spreadsheet would read as a formula gets a leading `'`, as in the
[table block](/blocks/table). The toolbar's view button is drawn but doesn't do anything
yet.

The toolbar's **Search table** button turns into a **Filter table…** box, as in Slack. As you
type, the table keeps only the rows with a cell that contains the term, ignoring case. Rich text
cells count too. The first occurrence of the term in each matching cell is highlighted. A filtered
table keeps the height of its first page. When no row matches, it shows **No results found.** and
a **Clear filter** button. **Clear** in the box empties it. Escape clears the term, closes the box
and puts focus back on the Search button. An empty box closes when focus leaves it, while a box
with a term stays open. Filtering starts again from page 1, and sorting applies to the rows left.

A cell shows one line, cut off with an ellipsis. When its content doesn't fit, hovering the cell
shows an **Expand cell** button, as in Slack. The button also shows on keyboard focus. It opens the
whole content in a **Cell content** dialog laid over the cell, as wide as it and scrolling past
144px. Escape or a click outside closes it. Like the menus, it acts in the page only and never calls
`onAction`.

### Numeric sorting

<Preview
  payload={{
    blocks: [
      {
        type: "data_table",
        rows: [
          [
            { type: "raw_text", text: "Name" },
            { type: "raw_text", text: "Amount" },
          ],
          [
            { type: "raw_text", text: "Acme Inc." },
            { type: "raw_number", value: 42000, text: "$42,000" },
          ],
          [
            { type: "raw_text", text: "Nimbus Corp." },
            { type: "raw_number", value: 8500, text: "$8,500" },
          ],
          [
            { type: "raw_text", text: "ShopCo Ltd." },
            { type: "raw_number", value: 120000, text: "$120,000" },
          ],
        ],
      },
    ],
  }}
/>

`raw_number` cells sort by their numeric `value`, not by the formatted `text`, so `$8,500` sorts below
`$42,000` even though `"$120,000"` would sort first alphabetically.
