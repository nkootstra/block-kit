---
title: Divider
description: A simple horizontal rule for visually separating blocks.
---

A divider renders a thin horizontal line. Use it to split up sections of a message or app
surface — it has no other fields to configure.

<Preview
  payload={{
    blocks: [{ type: "divider" }],
  }}
/>

## Fields

<TypeTable
  type={{
    type: {
      type: "string",
      description: 'Always `"divider"`.',
      required: true,
    },
    block_id: {
      type: "string",
      description:
        "A unique identifier for the block, up to 255 characters. Slack generates one if omitted.",
    },
  }}
/>

## Examples

### Between two sections

<Preview
  payload={{
    blocks: [
      {
        type: "section",

          type: "mrkdwn",
          text: "*Farmhouse Thai Cuisine*\n:star::star::star::star: 1528 reviews",

        accessory: {
          type: "image",

          alt_text: "alt text for image",

      { type: "divider" },
      {
        type: "section",

          type: "button",

  }}
