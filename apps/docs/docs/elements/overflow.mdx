`overflow` renders as a "⋮" button that opens a dropdown of up to 5 options. Reach for it when an
`actions` row or section accessory has more actions than fit as buttons.

<Preview
  payload={{
    blocks: [
      {
        type: "section",
        text: { type: "mrkdwn", text: "This is a section block with an overflow menu." },
        accessory: {
          type: "overflow",
          action_id: "overflow-action",
          options: [
            { text: { type: "plain_text", text: "Edit", emoji: true }, value: "value-0" },
            { text: { type: "plain_text", text: "Duplicate", emoji: true }, value: "value-1" },
            {
              text: { type: "plain_text", text: "Open docs", emoji: true },
              value: "value-2",
              url: "https://api.slack.com",
            },
            { text: { type: "plain_text", text: "Archive", emoji: true }, value: "value-3" },
            { text: { type: "plain_text", text: "Delete", emoji: true }, value: "value-4" },
          ],
        },
      },
    ],
  }}
  actions
/>

## Interactivity

Picking an item (after any confirm dialog is accepted) closes the menu, calls `onAction` with the
chosen option under `selected_option`, and opens the option's `url` in a new tab if it has one:

```json
{
  "type": "overflow",
  "action_id": "overflow-action",
  "block_id": "b1",
  "action_ts": "1706000000.000100",
  "selected_option": {
    "text": { "type": "plain_text", "text": "Open docs", "emoji": true },
    "value": "value-2",
    "url": "https://api.slack.com"
  }
}
```

The menu opens 250px wide, its left edge under the button's, as Slack's does; near the window's
right edge it shifts left to stay inside the window, as every menu and calendar does. Opening it moves
focus into the menu: the first ArrowDown highlights the first item, the arrow keys and Home/End move
the highlight, and Enter picks it. Escape or picking an item closes the menu and returns focus to
the button; an outside click closes it without moving focus. Like a button, overflow doesn't write
to `state.values`: it's a one-shot action, not a persisted value.
