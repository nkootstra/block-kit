`<BlockKitProvider>` holds the state of every input rendered beneath it, and is where interactions reach your code. It's optional: without one, blocks render and inputs work, but actions go nowhere.

```tsx
import { BlockKitProvider, Message } from "@nkootstra/block-kit";

<BlockKitProvider
  onAction={(action, { views, message, state }) => {}}
  onSubmit={(payload, { views }) => {}}
  onOptions={(payload) => ({ options: [] })}
  resolvers={{ user: (id) => users[id]?.name }}
>
  <Message blocks={blocks} />
</BlockKitProvider>;
```

One provider can hold several surfaces. Each action still carries the message or view it came from.
