Slack's API rejects a payload that breaks one of these limits: `chat.postMessage` answers with an
error such as `invalid_blocks` or `msg_blocks_too_long`, and `views.open` with
`invalid_arguments`. Every number on this page comes from Slack's own
reference at [docs.slack.dev](https://docs.slack.dev/reference/block-kit), linked next to it.
Limits Slack doesn't document are left out.

## What this package checks

`@nkootstra/block-kit` is a renderer, not a validator: it draws whatever payload you give it, even
one Slack would reject. A message with 60 blocks renders all 60. Check limits on your server before
you send a payload to Slack, or as your users type in an
[editor](/guides/block-kit-editor).

A few limits do change how the preview behaves, the same way they do in Slack's client:

| Limit                                       | What the renderer does                                                                                                         |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 3 views in a modal stack                    | `views.push` past the third view does nothing and logs a console warning. See [Modals](/guides/modals#the-3-view-stack-limit). |
| `min_length` / `max_length` on a text input | Shows the characters left while typing, and blocks Submit with Slack's message. See [Validation](/guides/validation).          |
| `min_value` / `max_value` on a number input | Blocks Submit with Slack's message.                                                                                            |
| `max_selected_items` on a multi-select      | Stops adding items at the limit and shows "You can select up to N items."                                                      |
| `max_files` on a file input                 | Keeps the first `max_files` files picked (10 when unset).                                                                      |
| `page_size` on a data table                 | Not read: the table always shows 5 rows per page, Slack's default.                                                             |

### Placeholders

The `placeholder` text on a select menu, multi-select menu, date picker, time picker,
`plain_text_input`, `email_text_input`, `url_text_input`, `number_input` and `rich_text_input` is
limited to 150 characters each (see each element's page, for example the
[select menu element](https://docs.slack.dev/reference/block-kit/block-elements/select-menu-element)).
