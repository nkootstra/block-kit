Block Kit Playground

Paste or edit Slack Block Kit JSON and see it rendered as a message, modal or Home tab, the way Slack draws it. You don't need to sign in to Slack or install anything.

The editor takes the JSON your app sends to chat.postMessage, views.open or views.publish: an object with blocks, a bare array of blocks, or a whole view. The preview follows as you type, and while the JSON doesn't parse it says what's wrong and keeps the last version that did.

Buttons, menus, date pickers and inputs work. Click one and the log under the preview shows the block_actions payload Slack would send your app, with its action_id, block_id and value, so you can check them before you write the handler.

The address keeps your JSON in Block Kit Builder's URL format, so a link copied from one opens in the other. The JSON stays in the link; nothing is saved on a server.

The playground is built on @nkootstra/block-kit, an open-source React package that renders Block Kit the way Slack does and is compared, pixel by pixel, against Slack's own rendering. Use it to show the same messages in your own product.
